# Política de privacidade do MyVitory

Última atualização: [DATA DA PUBLICAÇÃO]

O MyVitory é um app de planejamento de treino. Esta política explica quais dados ele usa e para onde vão.

## O que fica no seu celular

Seu plano semanal, os treinos feitos, cargas, repetições, vídeos fixados e ajustes ficam **apenas no seu aparelho**,
num banco de dados local. O MyVitory não tem servidor próprio, não pede cadastro e não envia esses dados para nós.

Se o backup do Android estiver ligado, o sistema pode copiar esses dados para a sua conta Google, como faz com outros
apps. Isso é controlado por você nas configurações do Android.

## O que passa pelo YouTube (Google)

- **Busca de vídeos:** quando você busca vídeos de um exercício, o termo buscado (por exemplo, "leg press execução
  correta") é enviado à YouTube Data API, do Google.
- **Reprodução:** os vídeos tocam no player oficial do YouTube dentro do app. O YouTube pode coletar dados de uso
  conforme a [Política de Privacidade do Google](https://policies.google.com/privacy) e os
  [Termos de Serviço do YouTube](https://www.youtube.com/t/terms).

## Notificações

Lembretes e o aviso de fim do descanso são gerados no próprio celular. Nada é enviado para fora para isso.

## O que não fazemos

Não usamos anúncios, não usamos ferramentas de análise ou rastreamento, não vendemos nem compartilhamos dados.

## Apagar seus dados

Desinstalar o app ou limpar os dados dele nas configurações do Android apaga tudo o que ele guardou no aparelho.
